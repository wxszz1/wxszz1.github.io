2026.11.24学习笔记（npm 安装、require 和测试命令）

发表于2026-11-24|更新于2026-11-28|学习笔记

今天在另一个项目里装了双模块实验包，跑了一次测试。安装和调用是我在终端操作的，实验代码和后面的配置修复有 AI 协助。

1. 装了包以后，代码怎么用它

我用 npm install 安装了实验包的 1.0.0 版本，再用 npm ls --depth=0 确认测试项目已经有这个直接依赖。依赖包就是项目运行时需要用到的外部代码，跟 Python 项目先用 pip 安装库差不多。

我一开始把 require() 理解成要这个包里的函数。更准确一点，它拿到的是包导出的内容。这次拿到的是两个对象 greeting 和 farewell，每个对象有 message 属性和 print() 方法。测试先检查属性，再调用方法，终端打印出两行日志：

2. 安装成功了，为什么 npm test 还会报错

有一轮安装和查看依赖都成功了，运行 npm test 却提示 Missing script: "test"。检查后发现测试目录里的 package.json 只剩依赖配置，index.js 也缺了。AI 帮我恢复入口和配置后，复跑又得到了上面两行输出。

看到这几行才知道，npm test 会去找项目里配置的测试命令。这个实验里它找到的是 node index.js，真正执行 JavaScript 的是 Node.js。下次看到同样的报错，我可以先检查当前目录和 package.json 里的 scripts。

3. npm 和 Git 都在管理什么

在 Python 项目里也会同时用 pip 和 Git。拿今天的实验来说，npm 用来发布和安装包，Git 用来记录源码改了什么。一个包可以由 Git 记录修改历史，再通过 npm 发布版本，给其他项目安装使用。
