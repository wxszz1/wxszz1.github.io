## 写文章的步骤

1. 使用 `npx hexo new post "english-slug"` 创建文章。
2. 修改标题、分类、标签，填写 Markdown 正文。
3. 使用 `npm run server` 预览，使用 `npm run build` 检查。
4. 提交并推送到 GitHub，等待两个网站自动更新。
