## 青光眼图像分类研究｜持续研究

围绕计算机能力挑战赛的图像分类任务，开展模型训练、验证、推理和实验复盘。探索 EfficientNet-B0、ConvNeXt、模型融合与不同训练方案，并保存模型版本、预测结果和实验记录。

这项实践也让我关注如何做可信的实验：区分开发验证与平台评分，保留负结果，避免用测试集调参，并为长时间训练准备断点恢复和评估流程。后续方案仍在验证中。

## Python 阅读清单后端｜学习实践

从文章的添加、查询、状态修改和文件保存出发，学习业务逻辑、存储与 HTTP 接口之间的分工。使用 FastAPI 提供接口、Uvicorn 运行服务，并用 Python 客户端封装请求。

当前重点是理解参数解析、JSON 响应、状态码和客户端调用；也在通过标准库 HTTP 服务的小实验理解框架背后的原理。

## Hacker News Agent｜工具开发

面向 AI 与 Agent 资讯，整理获取、筛选、存储和推送的处理流程。本地项目包含新闻抓取、关键词与热度筛选、SQLite 去重、定时调度和消息通知等模块，也在探索摘要、翻译与研究流程。

技术方向包括 Python、HTTP 客户端、任务调度与 SQLite。现阶段作为个人工具开发实践持续整理，不将其表述为已验证的长期稳定运营服务。

## GOAI Agent Infra｜方案与原型准备

围绕金融风控与保险理赔自动化整理业务流程、数据来源、核保与反欺诈知识，探索如何将多 Agent、Skill、MCP 与 RAG 组织到具体业务场景中。

这一方向强调从需求与业务理解出发，再逐步推进架构设计和实现；目前保留为方案与原型准备阶段，不代表已完成商业系统或取得竞赛奖项。
