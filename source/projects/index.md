## 个人技术博客

使用 Hexo + Butterfly 搭建的个人网站，收录技术文章、项目实践与学习笔记。

- **技术栈**：Hexo、Butterfly、Markdown、GitHub Actions、GitHub Pages
- **功能**：文章分类、全文搜索、文章归档、深色模式与自动部署
- [查看源码](https://github.com/wxszz1/wxszz1.github.io)

围绕“定长子串中元音的最大数目”记录滑动窗口的思路：进入窗口、更新答案、离开窗口，并保留当时手写的 C 代码。

## 这个网站的发布方式

文章使用 Markdown 编写，源码由 Git 和 GitHub 管理。推送后，GitHub Actions 构建静态页面；GitHub Pages 自动发布，服务器每分钟检查构建结果并同步博客文件。

从 CSDN 迁移的原创文章保留了原始日期、原文链接和本地图片。截图支持点击放大，也可以按原始尺寸查看。
